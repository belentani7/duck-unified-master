# Achados de recursos externos

| Fonte | Recurso | Evidência | Avaliação inicial |
|---|---|---|---|
| GitHub | [audioFlux](https://github.com/libAudioFlux/audioFlux) | README declara biblioteca de análise musical e extração de características, com licença MIT; inclui algoritmos de pitch, transformações e rastreamento de afinação. | **Candidato condicionado.** Útil para pipeline futuro de metadados de áudio fora do runtime web. Não integrar no container atual: envolve dependência nativa/Python e processamento de áudio que excede o escopo de requisições curtas. |
| Hugging Face | [Stable Audio Open 1.0](https://huggingface.co/stabilityai/stable-audio-open-1.0) | Cartão do modelo exige aceite da licença e informa que uso comercial deve seguir a licença da Stability AI. | **Excluído da integração automática.** Não deve ser incorporado nem usado para gerar catálogo comercial até revisão contratual, aprovação do proprietário e infraestrutura compatível. |
| Fonte financeira aberta | [Open Finance Brasil — Banco Central do Brasil](https://www.bcb.gov.br/en/financialstability/open_finance) | O BCB define o ecossistema como compartilhamento de dados, produtos e serviços entre entidades reguladas, a critério do cliente. Consentimento livre, informado, prévio e inequívoco é obrigatório; autorização pode ser revogada. | **Referência de arquitetura, não integração direta.** Duck Studio não é instituição regulada. Não acessar contas, iniciar pagamentos ou receber dados transacionais sem parceiro regulado, fluxo de consentimento, autenticação e confirmação. |
| GitHub | [Tone.js](https://github.com/Tonejs/Tone.js) | Repositório descreve framework Web Audio para música interativa em navegador, com transporte, síntese, efeitos e licença MIT. | **Candidato viável.** Pode enriquecer prévias autorizadas, metrônomo e visualização interativa do Beat Lab no cliente. Não inclui nem licencia áudios de terceiros; integrar somente após o proprietário fornecer previews. |
| Hugging Face | [PDMX](https://huggingface.co/papers/2409.10831) | Página do artigo descreve mais de 250 mil partituras MusicXML de domínio público para pesquisa de música simbólica multifaixa. | **Candidato de pesquisa, não ativo comercial.** Pode orientar presets, estruturas e experimentos de MIDI em ambiente separado. Não utilizar para preencher catálogo, redistribuir partituras ou gerar alegações de autoria. |
| GitHub | [music-metadata](https://github.com/Borewit/music-metadata) | Repositório TypeScript com licença MIT para ler metadados de arquivo e stream em Node.js e navegador, incluindo duração, bitrate e formatos comuns como MP3, WAV, FLAC e M4A. | **Candidato viável.** Pode reduzir entrada manual ao importar arquivos reais no gestor de ativos. Integrar somente em upload autenticado, com limite de tamanho e sem alterar metadados de origem. |
| Dados abertos | [Portal de Dados Abertos do Banco Central](https://opendata.bcb.gov.br/en/dataset/?res_format=API) | Portal oficial lista datasets públicos em API, JSON e OData, incluindo cotações e dados agregados; a página indica licença ODbL para os datasets filtrados. | **Candidato de contexto agregado.** Pode alimentar um painel informativo opcional de macroindicadores, com fonte e data visíveis. Não usar para perfil financeiro de pessoas, preços automáticos, crédito, pagamento ou recomendação de investimento. |
