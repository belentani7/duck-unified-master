# Referências de auditoria verificadas

O OWASP ASVS mantém a versão estável **5.0.0** como referência atual para requisitos verificáveis de segurança de aplicações web. O prompt adaptado para Duck Studio usará esse padrão apenas para controles proporcionais ao aplicativo, sem declarar conformidade integral sem evidências de teste.

O NIST Cybersecurity Framework 2.0 é utilizado como estrutura de gestão de risco. Ele orienta governança e melhoria contínua, mas não substitui uma configuração de infraestrutura nem constitui uma certificação automática.

## Fontes

- OWASP ASVS: https://owasp.org/www-project-application-security-verification-standard/
- NIST Cybersecurity Framework: https://www.nist.gov/cyberframework
