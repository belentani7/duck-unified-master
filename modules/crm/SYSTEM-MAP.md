# DUCK ECOSYSTEM — System Map

## Core systems

### DUCK Studio Pro
Music production domain: projects, stems, versions, comments, audit.

### DUCK / ZION
Experience, portal, toolkit, automation and presentation layer.

### Gema Nº 01
Creative toolkit, instruments and visual identity laboratory.

### Duck Studio Local
Local workstation, DAW, plugins and local knowledge.

### Duck Omega
Reasoning and automation layer.

### AION Workforce
Agent orchestration and action layer.

### Nexus Workforce / Nexus AION
Enterprise-oriented orchestration experiments.

### NOIACORE
AI laboratory and experimentation layer.
