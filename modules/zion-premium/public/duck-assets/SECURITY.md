# Política de Segurança

## Reportar Vulnerabilidades

Se você encontrar uma vulnerabilidade de segurança, **não** abra uma issue pública.

Envie um email para: `contato@duckmusic.com.br` com:

- Descrição da vulnerabilidade
- Passos para reproduzir
- Possível impacto
- Sugestão de correção (se houver)

## Resposta

- **Confirmação**: Em até 48 horas
- **Correção**: Priorizada conforme gravidade
- **Crédito**: Quem reportar será creditado (a menos que prefira anonimato)

## O que NÃO reportar

- Problemas de design/UX
- Funcionalidades que funcionam mas poderiam ser "melhores"
- Pedidos de novas funcionalidades
