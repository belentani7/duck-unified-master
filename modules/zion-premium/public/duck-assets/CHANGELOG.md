# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/),
e este projeto adere ao [Semantic Versioning](https://semver.org/lang/pt-BR/).

## [2.0.0] - 2026-07-27

### Adicionado
- Arquitetura modular CSS (19 arquivos)
- Arquitetura modular JS (5 arquivos)
- Data-driven architecture (data.js)
- Sistema de design tokens
- Instrumentos interativos (Piano, Rhythm Box, Voice, Recorder)
- Suporte a 4 idiomas (PT, EN, ES, FR)
- Smooth scroll com Lenis
- Animações GSAP premium
- Custom cursor
- Scroll progress indicator
- Skip navigation
- ARIA labels completos
- Reduced motion support
- Formulário de contato
- SEO otimizado (Open Graph, JSON-LD)
- Scripts de build e deploy
- CI/CD com GitHub Actions

### Melhorado
- Performance: lazy loading, preload hints
- Acessibilidade: WCAG 2.1 AA
- Responsivo: mobile-first
- Tipografia: escala modular
