# 🚀 DUCK Studio - Quick Start Guide

**Get started with DUCK Studio in 5 minutes!**

---

## ⚡ Installation (< 1 minute)

### Step 1: Open the File
```bash
# Simply open duck-studio.html in your browser:
firefox duck-studio.html
chromium duck-studio.html
# or drag-and-drop the file into your browser
```

### Step 2: Click to Enable Audio
The browser will suspend audio by default. Click anywhere on the page to activate the Web Audio API context.

### Step 3: You're Ready!
The studio is fully loaded and ready to create music. 🎵

---

## 🎹 5-Minute Tutorial

### Minute 1: Play the Piano

1. Scroll to **MIDI PIANO CONTROLLER** section
2. Click on any key to play a note
3. Listen to the synthesized sound
4. Try playing a melody (multiple notes)

**Tip:** Each key shows the note name (e.g., C3, D3, E3)

---

### Minute 2: Play the Drums

1. Scroll to **DRUM MACHINE (16 Pads)** section
2. Click on any pad to trigger a drum sound
3. Try different sounds: Kick, Snare, Hi-Hat, etc.
4. Click quickly to create a beat

**Tip:** Combine different drums to create rhythms

---

### Minute 3: Control the Mixer

1. Scroll to **AUDIO MIXER (8 Channels)** section
2. You'll see 8 vertical faders (sliders)
3. Drag each fader up/down to adjust volume
4. Watch the dB value change in real-time
5. Adjust all channels to balance the mix

**Tip:** Start with Master at 0dB, then adjust individual channels

---

### Minute 4: Use the Sequencer

1. Scroll to **16-STEP SEQUENCER** section
2. Click on any of the 16 cells to toggle it ON/OFF
3. Click the **PLAY** button to start playback
4. Watch the sequencer loop
5. Click cells while playing to add/remove beats

**Tip:** Create drum patterns for automatic beats

---

### Minute 5: Add Effects

1. Scroll to **AUDIO EFFECTS & PLUGINS** section
2. Click on any effect box (e.g., Reverb, Delay)
3. The box will glow to show it's active
4. Click again to deactivate
5. Combine multiple effects for complex sounds

**Tip:** Reverb + Delay creates spacious ambience

---

## 🎮 Master Controls

Located right above the mixer section:

```
┌─────────────────────────────────────────┐
│         MASTER CONTROLS                 │
├─────────────────────────────────────────┤
│ ▶️  PLAY      - Start playback          │
│ 🔴 RECORD    - Record what you play     │
│ ⏹️  STOP      - Stop recording          │
│ 🗑️  CLEAR     - Clear sequencer         │
│ 🎵 METRONOME - Add click track          │
└─────────────────────────────────────────┘
```

### Using RECORD Mode
1. Click **RECORD** button (it will pulse with red)
2. Play piano, drums, or sequencer
3. Click **STOP** to finish recording
4. Check the timer to see duration

## 📚 Common Workflows

### Create a Simple Beat

1. **Go to Drum Machine section**
2. **Create a pattern:**
   - Kick on beats 1, 5, 9, 13
   - Snare on beats 5, 13
   - Hi-Hat on every beat
3. **Use Sequencer:**
   - Click those 16 cells to create the pattern
4. **Playback:**
   - Click PLAY to loop
5. **Adjust Volume:**
   - Use Mixer faders to balance

---

### Play a Melody with Effects

1. **Select an Effect:**
   - Click on Reverb in the plugins section
2. **Play Piano:**
   - Click piano keys to create melody
3. **Add Delay:**
   - Click on Delay plugin (now you have 2 effects!)
4. **Adjust Mixer:**
   - Set Master channel to medium volume
5. **Control Amount:**
   - Use knobs (Filter, Resonance, etc.)

---

### Record Your Performance

1. **Prepare:**
   - Click RECORD button (shows pulsing red)
   - Timer starts at 00:00:00
2. **Play:**
   - Click piano keys
   - Trigger drum pads
   - Click sequencer cells
3. **Stop:**
   - Click STOP button
   - Timer shows total time
4. **Repeat:**
   - Create multiple layers

### Tip 8: Experiment with Knobs
Try all 6 control knobs to hear how they shape the sound.

- ✅ Make sure you clicked on the page first
- ✅ Refresh browser (Ctrl+F5)
- ✅ Try a different browser
- ✅ Check browser console for errors

### Too Loud?
- ✅ Lower Master fader in mixer
- ✅ Lower system volume
- ✅ Reduce number of active sounds
- ✅ Use headphones with volume control

## 🎵 Sound Design Ideas

### Create a Pad Sound
1. Keep notes sustained in Piano
2. Add Reverb effect
3. Add Delay effect
4. Mix with lower faders
5. Result: Spacious ambient pad

### Create a Kick Drum
1. Use Kick pad in Drum Machine
2. Add a tiny bit of Distortion
3. Slightly reduce Master volume
4. Result: Punchy kick drum

### Create a Snare Hit
1. Use Snare pad in Drum Machine
2. Add Reverb for space
3. Keep volume high
4. Result: Crisp snare

### Create a Synth Bass
1. Play low notes on Piano (C3, D3)
2. Add EQ plugin (low-pass filter)
3. Add Compression
4. Reduce Master volume to bass level
5. Result: Warm bass line
