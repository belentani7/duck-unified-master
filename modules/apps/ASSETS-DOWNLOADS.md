## 🎯 Como Usar Assets no DUCK Studio

### Método 1: Drag & Drop
```
1. Download samples
2. Abra duck-studio.html
3. Arraste WAV/MP3 para a janela
4. Selecione track/pad
5. Clique para reproduzir
```

### Método 2: Importar como Loop
```
1. Prepare o sample (trim, normalize)
2. Carregue no sequencer
3. Configure BPM matching
4. Sincronize com outras tracks
5. Exporte mix final
```

### Método 3: Camadas (Layering)
```
1. Load drum kit #1 (pads 1-4)
2. Load drum kit #2 (pads 5-8)
3. Load additional sounds (pads 9-16)
4. Ajuste volumes no mixer
5. Crie combinações únicas
```

```

```
